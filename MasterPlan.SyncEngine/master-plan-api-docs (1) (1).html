     -H "X-API-Key: Mp_CLIENT4-KEY-112289-KLMNO_2026" \
     -H "Accept: application/json"

טיפול בשגיאות

ה-API עשוי להחזיר קודי שגיאה שונים. להלן הקודים העיקריים וההסבר שלהם:

401 Unauthorized

מפתח ה-API חסר או שגוי. יש לוודא שה-Header X-API-Key נשלח עם כל בקשה ומכיל את המפתח הנכון.

404 Not Found

הכתובת (Endpoint) אינה נכונה. יש לוודא שה-URL תקין ושהמסלול נכון.

500 Internal Server Error

שגיאה פנימית בשרת. במקרה זה יש לפנות לתמיכה הטכנית של Master Plan.
