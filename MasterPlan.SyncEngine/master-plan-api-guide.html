אימות והתחברות

הגישה ל-API דורשת מפתח אימות ייחודי שיש לכלול ב-Header של כל בקשת HTTP.

Base URL: https://mpwebd.master-plan.co.il/MPWebAPI/api/projects/
Header Name: X-API-Key
API Key: CLIENT3-KEY-22222-KLMNO

דוגמאות קוד

cURL

curl -X GET "https://mpwebd.master-plan.co.il/MPWebAPI/api/projects/" \
     -H "X-API-Key: CLIENT3-KEY-22222-KLMNO" \
     -H "Accept: application/json"

JavaScript (Fetch)

const response = await fetch('https://mpwebd.master-plan.co.il/MPWebAPI/api/projects/', {
    method: 'GET',
    headers: {
        'X-API-Key': 'CLIENT3-KEY-22222-KLMNO',
        'Content-Type': 'application/json'
    }
});

const data = await response.json();
console.log(data);

טיפול בשגיאות

ה-API עשוי להחזיר קודי שגיאה שונים. להלן הקודים העיקריים וההסבר שלהם:

401 Unauthorized

מפתח ה-API חסר או שגוי. יש לוודא שה-Header X-API-Key נשלח עם כל בקשה ומכיל את המפתח הנכון.

404 Not Found

הכתובת (Endpoint) אינה נכונה. יש לוודא שה-URL תקין ושהמסלול נכון.

500 Internal Server Error

שגיאה פנימית בשרת. במקרה זה יש לפנות לתמיכה הטכנית של Master Plan.
